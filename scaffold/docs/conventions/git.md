# Git conventions (Project Ledger)

1. Intent before non-trivial code (REQ + SPEC@rev + PLAN).
2. Never rewrite immutable SOW/SPEC revisions or accepted ADRs — supersede.
3. Append-only `.audit/events.jsonl`.
4. Trace files in TASK/CHG `files:` lists.
5. Evidence before claiming done.
6. Security/code review for sensitive changes.
7. Match existing codebase style.
